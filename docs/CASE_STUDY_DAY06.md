# 实操范例：第6天扎兰屯至海拉尔

这个范例说明如何做一次真实的**资料研究与虚拟行程编排**。它不是一篇可直接复制的当日日志，也不表示作者实际开车到访。原运行目录在 2026-11-22 完成第6天；迁移时以目标目录最新 `旅行状态.json` 为准。

## 输入

前一日状态：`journey_status=active`、`last_completed_day=5`、`last_completed_log_date=2026-11-21`、住宿地扎兰屯市区、`next_day=6`。`next_five_anchors` 首项为海拉尔城区，随后是海拉尔驻留、额尔古纳、根河、满归；齐齐哈尔已关闭。原日志第5天明确次日北上，不允许在扎兰屯再开新专题。

## 研究决策

1. **目的地**：选择五站第一项海拉尔城区，夜宿海拉尔站—中央桥一带。第7天仍宿海拉尔，第8天转额尔古纳。
2. **核心问题**：铁路和两条河怎样组织呼伦贝尔中心城区。长距离驾驶日不塞进纪念园深度参观；日军要塞的史料研究留第7天。
3. **路线**：开放道路模型从扎兰屯市区参考点到海拉尔城区参考点约326.3公里、模型纯驾驶约3小时52分，出现牙四线、G301、G10等路段。日志给冬季驾驶、补给与延误留6—7小时。模型不证明道路在当天畅通；途中博克图、免渡河仅作方向线索。
4. **统计**：海拉尔区2025统计公报的GDP为248.1938亿元，三次产业比3.8∶20.1∶76.1，年末**户籍**人口285053人；呼伦贝尔市七普公报中的海拉尔区2020**常住**人口365012人。两组人口不相减。区政府介绍的1440平方公里为区境，64.4平方公里为建成区。
5. **规划版本**：2022年呼伦贝尔规划公众草案PDF第23页可直接看中心城区布局；2025年公开的批准文本第40—47页把结构定为“一城、两廊、六片、四板块”，并写“东聚南联、西优北控”。草案的“五片”与批准文本的“六片”不同，图注要提醒读者。
6. **图像**：批准版PDF第78页市域图给区域第一印象；草案第23页看城区布局；另做路线SVG并标非测绘底图。两张政府发布的海拉尔城区及哈萨尔大桥图片用于第一印象，分别注明页面日期、素材上传时间和拍摄日未知，不当作当天现场。
